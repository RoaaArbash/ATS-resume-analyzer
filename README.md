# ATS Resume Analyzer

A web application that evaluates resumes against common Applicant Tracking System (ATS) criteria and provides actionable feedback to improve compatibility.

## Features

* Upload PDF, PNG, or JPG resumes
* Extract text from PDF documents using OCR
* Analyze resume structure and essential sections
* Detect missing contact information
* Evaluate skills and keyword relevance
* Generate an ATS compatibility score
* Identify detected issues and strengths
* Provide optimization recommendations
* Support job description keyword matching

## Tech Stack

* React
* Vite
* Tailwind CSS
* PDF.js
* Tesseract.js
* React Router

## Getting Started

```bash
git clone https://github.com/RoaaArbash/ATS-resume-analyzer.git
cd ATS-resume-analyzer
npm install
npm run dev
```

## Supported Formats

* PDF
* PNG
* JPG
* JPEG

## Disclaimer

This project provides an estimated ATS compatibility analysis based on predefined rules and heuristics. It does not replicate or guarantee the behavior of proprietary Applicant Tracking Systems.
