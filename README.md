# ATS Resume Analyzer

A professional web application that evaluates resumes against common Applicant Tracking System (ATS) criteria and provides structured feedback to help improve resume compatibility.

## Features

- Upload resumes in PDF, PNG, JPG, or JPEG format
- Extract text from text-based PDF documents using PDF.js
- Extract text from image-based resumes using OCR with Tesseract.js
- Analyze resume structure and essential sections
- Detect missing contact information
- Evaluate skills and keyword relevance
- Generate an ATS compatibility score
- Identify detected issues and strengths
- Provide actionable optimization recommendations
- Support job description keyword matching

## Tech Stack

- React
- Vite
- Tailwind CSS
- PDF.js
- Tesseract.js
- React Router

## Supported Formats

- PDF
- PNG
- JPG
- JPEG
